## 기술적 세부사항

### OAuth 구현 특징
1. **멀티 제공자 지원:** Google, GitHub, Facebook
2. **계정 연동:** 기존 이메일 기반 계정과 OAuth 계정 자동 연동
3. **사용자 검증:** OAuth 사용자는 자동으로 검증된 상태

5. **JWT 토큰:** 표준 JWT 형식으로 인증 정보 전달
6. **프론트엔드 통합:** 콜백 URL을 통한 자동 리다이렉트

### 보안 고려사항
- CSRF 방어를 위한 state 파라미터 사용
- 제한적인 OAuth 스코프 (이메일, 프로필만)
- 적절한 rate limiting 설정

- **OAuth DTO 클래스 생성**

- **Global Validation Pipe 개선**
  - 향상된 에러 처리 및 메시지 포맷팅
  - Transform 옵션 및 보안 설정 강화
  - Production 환경에서 에러 메시지 숨김

#### ✅ CORS 설정 강화
- **전용 CORS 설정 파일 생성** (`config/cors.config.ts`)
  - 환경별 허용 도메인 분리 (개발/프로덕션)
  - 동적 origin 검증 로직
  - 보안 헤더 및 메서드 제한
  - 24시간 preflight 캐싱

#### ✅ Rate Limiting 시스템 구축
- **다단계 Throttling 설정**
  - Short: 1초당 3요청
  - Medium: 10초당 20요청  
  - Long: 1분당 100요청
- **OAuth 엔드포인트 특별 제한**
  - OAuth 로그인: 1분당 5회
  - 일반 Auth: 1분당 10회
- **ThrottlerGuard 전역 적용**

#### ✅ Input Sanitization 보안
- **SanitizationPipe 구현**
  - HTML 태그 제거
  - XSS 방지를 위한 특수문자 이스케이프
  - SQL Injection 패턴 감지 및 제거
  - 객체 및 배열 재귀적 정제

#### ✅ 보안 헤더 강화 (Helmet)
- **Content Security Policy 설정**
  - 엄격한 리소스 출처 제한
  - 인라인 스크립트/스타일 제어
  - 외부 프레임 차단
- **기타 보안 헤더**
  - X-Frame-Options, X-Content-Type-Options
  - Referrer-Policy, Permissions-Policy

## Phase 3.1 완료 - 핵심 이미지 업로드 시스템 (완료)

### 구현된 이미지 업로드 기능들

#### ✅ 필수 패키지 설치
- `multer@2.0.2`: 다중 파일 업로드 처리
- `sharp@0.34.3`: 고성능 이미지 처리 및 리사이징
- `@types/multer@2.0.0`: TypeScript 지원

#### ✅ 이미지 업로드 설정 (`config/upload.config.ts`)
- **파일 검증**
  - 지원 형식: JPEG, PNG, WebP, GIF, BMP, TIFF
  - 최대 파일 크기: 50MB
  - 최대 파일 수: 10개 동시 업로드
- **저장소 구조**
  - 임시 저장: `uploads/temp/`
  - 사용자별 디렉토리: `uploads/{userId}/`
  - 해상도별 폴더: `thumbnails/`, `medium/`, `large/`, `original/`

#### ✅ 이미지 처리 서비스 (`ImageProcessingService`)
- **다중 해상도 생성**
  - Thumbnail: 300x300 (cover, 80% quality)
  - Medium: 800x800 (fit inside, 85% quality)
  - Large: 1200x1200 (fit inside, 90% quality)
  - Original: 최적화된 원본 (95% quality)
- **WebP 변환**: 썸네일, 미디엄, 라지는 WebP로 최적화
- **메타데이터 추출**: 너비, 높이, 형식, 크기, 비율, 알파채널, 색공간
- **임시 파일 정리**: 처리 완료 후 자동 삭제

#### ✅ 이미지 서비스 (`ImagesService`)
- **업로드 처리**
  - 파일 검증 및 메타데이터 추출
  - 다중 해상도 이미지 생성
  - 데이터베이스 저장 (기존 Images 엔티티 활용)
  - 사용자 업로드 카운트 업데이트
- **CRUD 작업**
  - 이미지 조회 (페이지네이션, 필터링)
  - 이미지 수정 (소유자만)
  - 이미지 삭제 (소프트 삭제, 물리 파일 삭제)
  - 조회수 증가 (중복 방지)

#### ✅ 이미지 컨트롤러 (`ImagesController`)
- **업로드 엔드포인트**
  - `POST /images/upload`: 다중 이미지 업로드
  - Rate limiting: 1분당 10회
  - JWT 인증 필수
- **조회 엔드포인트**
  - `GET /images`: 공개 이미지 목록 (페이지네이션)
  - `GET /images/{id}`: 개별 이미지 조회
  - `GET /images/user/{userId}`: 사용자별 공개 이미지
  - `GET /images/my/images`: 내 이미지 (비공개 포함)
- **관리 엔드포인트**
  - `PUT /images/{id}`: 이미지 정보 수정
  - `DELETE /images/{id}`: 이미지 삭제

#### ✅ DTO 및 타입 시스템
- `UploadImageDto`: 업로드 시 메타데이터 검증
- `ImageResponseDto`: 응답 데이터 구조화
- `ImageUrlsDto`, `ImageMetadataDto`: 세부 정보 타입

#### ✅ 정적 파일 서빙
- `/uploads/*` 경로로 이미지 파일 직접 접근
- Express static middleware 설정
