- **`ImagesService`:** Added a `getDownloadUrl` method that orchestrates finding an image and calling the appropriate storage service to get the download URL. The implementation handles parsing the key from the S3 URL.
- **`ImagesController`:** Added the `GET /:id/download` endpoint, which returns the generated URL in a JSON object.
